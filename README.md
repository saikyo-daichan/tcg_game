# デュエルデュエル (DUEL DUEL)

ブラウザで遊べるカードバトル。PC・スマホ対応（マウス / タッチ / ドラッグ＆ドロップ / キーボード）。

- `index.html` を開くと始まります（GitHub Pages: Settings → Pages → Branch `main` / `(root)`）。
- CPU対戦・チュートリアル・デッキ構築・ショップ・クエストはオフラインでも遊べます（一度読み込むとキャッシュされます）。
- 野良対戦・部屋対戦はインターネット経由のP2P（PeerJS）。
- セーブデータは端末ごとのID（プロフィールのプレイヤー番号）に紐づけてブラウザ内に保存されます。
